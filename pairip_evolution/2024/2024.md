Firstly download the termux from here:
https://github.com/HardcodedCat/termux-monet

Give storage permission to the termux,update pkgs and install python using the below command:

termux-setup-storage && pkg update -y && pkg upgrade -y && pkg i python -y

Now place the script and apk (Note: you can put any one of these .apks, .apkm and .xapk script will merge automatically) in one folder then use the script(python pairip_utility.py).(Make sure the folder contains only one APK)


将pairip那个apk中所有dex添加都original，然后使用original安装到root，提取到mtd



Install the patched APK directly without signing (Root needed or install in VM and give storage permission) (Thanks to sumanta for this idea) and open it,then go to the MT manager and translate dex using translation mode.(Choose Provider in translation mode to our newly generated dictionary.)

For Non-VIP users change the dictionary name to DefaultDictionary.mtd and translate.

const-string v0,$1

Goto this class

com.pairip.application.Application 

then go inside the super class line then copy the class name(by tapping on the class name it will show menu)after that delete com/pairip folder... 

After this choose all options in removing debug info and save it.

Now open AndroidManifest.xml with "String Pool" search/filter .*pairip.* and replace it with the class name that we copied.


不删除License Check


In some apps, There are new License Check classes are added by Pairip. To handle this, I have updated Regex 5.1 (thanks to Ali) to skip deleting License Check invokes. From now on, do not delete License Check classes(if there). Also, while replacing class name in the AndroidManifest, only replace the Pairip Application class.
